# Common Network Security Threats Report

This project explains four common network security threats:

- DoS/DDoS attacks
- Man-in-the-Middle (MITM) attacks
- IP Spoofing
- DNS Poisoning

The report covers the working, impact, real-world examples, and mitigation strategies for each threat.
