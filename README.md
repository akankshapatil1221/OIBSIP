# Oasis Infobyte Cybersecurity Internship (OIBSIP)

Welcome to my repository for the **Oasis Infobyte Cybersecurity Internship Program (OIBSIP)**. This repository contains all the completed practical tasks, security analysis reports, technical documentation, and demonstration evidence.

---

## 📁 Repository Structure & Task Overview

### 1. [CyberSecurity-Task3-SQL](./CyberSecurity-Task3-SQL)
* **Task Title**: SQL Injection on DVWA (Low Security)
* **Description**: Demonstrated classic SQL Injection techniques on Damn Vulnerable Web Application (DVWA). Extracted backend database metadata, mapped user records, dumped MD5 password hashes using `UNION SELECT` payloads, and cracked hashes using Rainbow Tables. Included remediation via Prepared Statements.

### 2. [CyberSecurity-Task4-NetworkThreatsReport](./CyberSecurity-Task4-NetworkThreatsReport)
* **Task Title**: Network Threats & Vulnerability Analysis
* **Description**: Detailed report analyzing modern network threats, attack vectors, port scanning techniques, and mitigation strategies for enterprise network security.

### 3. [CyberSecurity-Task5-SocialEngineering](./CyberSecurity-Task5-SocialEngineering)
* **Task Title**: Social Engineering Attacks & Awareness
* **Description**: Study of human-centric attack vectors including Phishing, Spear Phishing, Baiting, and Pretexting. Outlined attack methodologies and defensive countermeasures.

### 4. [CyberSecurity-Task8-Wireshark](./CyberSecurity-Task8-Wireshark)
* **Task Title**: Network Traffic Analysis using Wireshark
* **Description**: Packet capture and protocol analysis using Wireshark. Inspected network traffic logs to identify unencrypted credentials, protocol anomalies, and malicious packet behavior.
